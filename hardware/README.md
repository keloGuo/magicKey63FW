# Hardware Files

This directory stores hardware design files for the keyboard electronics.

Suggested contents:

- Schematics.
- PCB layout source files.
- BOM files.
- Gerber and drill exports.
- Pick-and-place files.
- Assembly drawings and notes.
- Pinout and wiring reference documents.

Keyboard enclosure and mechanical 3D files are stored separately in
`case_3d/`.
