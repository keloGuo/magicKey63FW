# Case 3D Files

This directory stores keyboard enclosure and mechanical structure files.

## Current Files

- `上盖&定位板.step`: Top cover and positioning plate.
- `键盘底盖V3.1.7.step`: Keyboard bottom cover.
- `空格键帽.step`: Spacebar keycap.

## File Types

Preferred source formats:

- `STEP` / `STP`: Mechanical source exchange format.
- `3MF`: 3D printing project format.
- `STL`: 3D printing mesh export.
- `DXF`: 2D plate or outline export.

When adding generated exports, keep the editable source file as well.
